# ZEE PAY - مشروع تجريبي

تطبيق محفظة رقمية تجريبية باللغة العربية باستخدام Python وFlet.

## التشغيل على الكمبيوتر

1. ثبّت Python 3.10 أو 3.11.
2. افتح الطرفية داخل مجلد المشروع.
3. نفّذ:

```bash
python -m pip install -r requirements.txt
python main.py
```

## البناء لهاتف Android

يتطلب بناء APK بيئة بناء مناسبة وFlutter/Android SDK حسب تعليمات Flet.

```bash
python -m pip install -r requirements.txt
flet build apk
```

قد تحتاج إلى إعداد Android SDK وJava وFlutter على الكمبيوتر قبل البناء. يفضل بناء APK على كمبيوتر، وليس من Pydroid 3.

## تجربة التطبيق

- أنشئ حساباً برقم هاتف تجريبي ورمز PIN من 4 أرقام أو أكثر.
- سجّل الدخول.
- يمكن إنشاء مستخدم ثانٍ على نفس قاعدة البيانات لاختبار التحويل.
- هذه النسخة لا تتصل بالبنوك أو شبكات الدفع، ولا تحتفظ بأموال حقيقية.
- زر الإيداع التجريبي يضيف 1,000 SDG للاختبار فقط.

## تنبيه أمني وقانوني

هذه نسخة أولية تعليمية. قاعدة البيانات محلية ورمز PIN غير مناسب للإنتاج. لا تستخدمها لأموال العملاء. يلزم خادم آمن، تشفير وإدارة مفاتيح، تحقق هوية، سجل مالي موثوق، واختبارات أمنية، وشراكة مع مزود دفع مرخص وموافقات الجهات المختصة قبل أي تشغيل مالي حقيقي.
