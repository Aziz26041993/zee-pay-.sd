حزمة شعار ZEE PAY

1) فك ضغط هذا الملف.
2) ارفع مجلد assets إلى جذر مستودع GitHub بجانب main.py.
3) داخل main.py اجعل صورة الشعار تستخدم المسار: zee_logo.png
4) شغّل التطبيق مع assets_dir="assets" في ft.app.

مثال:
ft.app(target=main, assets_dir="assets")

هذه الحزمة تحتوي صورة الشعار فقط، ولا تعدّل ملفات GitHub تلقائياً.
